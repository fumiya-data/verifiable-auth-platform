# パスワード認証状態機械 (engine/ core)

この文書は [`../docs/state-machine.md`](../docs/state-machine.md) の日本語版です。

範囲
----
- 対象は 1 つのユーザーアカウントに絞る。
- 状態は次の合成である:
  - session state: `state.authenticated`, `state.authenticated_login_id`
  - account state: `user.lock_state`, `user.failed_attempts`
  - `AUTH_LOCKOUT_THRESHOLD = 3`

状態定義
--------
[N ] : ユーザーが存在しない
[U0] : 非認証、ユーザーあり、lock=ACTIVE、failed_attempts=0
[U1] : 非認証、ユーザーあり、lock=ACTIVE、failed_attempts=1
[U2] : 非認証、ユーザーあり、lock=ACTIVE、failed_attempts=2
[UL] : 非認証、ユーザーあり、lock=LOCKED、failed_attempts>=3
[SA] : このユーザーとして認証済み、lock=ACTIVE、failed_attempts=0


主状態遷移図
------------
```text
┌──────────────────────────┐
│ [N ]                     │
│ 未登録                   │
└─────────────┬────────────┘
  ├─ ↺ login(any) / UNKNOWN_USER
  │     状態は変化しない
  │
  └─ register / SUCCESS
              ▼
┌──────────────────────────────────┐
│ [U0]                             │
│ 非認証, Active                   │
│ failed_attempts = 0              │
└─────────────┬────────────────────┘
              ├─ login(wrong)
              │  / WRONG_PASSWORD
              ▼
┌──────────────────────────────────┐
│ [U1]                             │
│ 非認証, Active                   │
│ failed_attempts = 1              │
└─────────────┬────────────────────┘
              ├─ login(wrong)
              │  / WRONG_PASSWORD
              ▼
┌──────────────────────────────────┐
│ [U2]                             │
│ 非認証, Active                   │
│ failed_attempts = 2              │
└─────────────┬────────────────────┘
              ├─ login(wrong)
              │  / LOCKED_OUT
              │  failed_attempts = 3
              │  lock = LOCKED
              ▼
┌──────────────────────────────────┐
│ [UL]                             │
│ 非認証, Locked                   │
│ failed_attempts >= 3             │
└──────────────────────────────────┘
  ↺ login(any) / LOCKED_OUT
    変更なし

[U0], [U1], [U2]
  └─ login(correct) / SUCCESS
     failed_attempts を 0 に戻す
     session を設定する
     ▼
┌──────────────────────────────────┐
│ [SA]                             │
│ このユーザーとして認証済み       │
│ lock = ACTIVE                    │
│ failed_attempts = 0              │
└─────────────┬────────────────────┘
              ├─ ↺ login(any) / ALREADY_AUTHENTICATED
              │     変更なし
              ├─ ↺ change_password(wrong old) / WRONG_PASSWORD
              │     変更なし
              ├─ ↺ change_password(correct old, new) / SUCCESS
              │     salt を再生成
              │     password_hash を置換
              │     failed_attempts = 0
              │     lock = ACTIVE
              │     session は保持
              └─ logout() / SUCCESS ─────────────────────────► [U0]
                  authenticated = false
```

ログイン判定順序 (厳密)
----------------------
`auth_login(state, login_id, password)`

    1. if state.authenticated == true
         -> ALREADY_AUTHENTICATED
         -> 即座に return

    2. user = find_user_mut(state, login_id)
       if user == NULL
         -> UNKNOWN_USER
         -> return

    3. if user.lock_state == LOCKED
         -> LOCKED_OUT
         -> return

    4. if password verification fails
         -> user.failed_attempts += 1
         -> if user.failed_attempts >= 3
              user.lock_state = LOCKED
              return LOCKED_OUT
            else
              return WRONG_PASSWORD

    5. password verification succeeds
         -> user.failed_attempts = 0
         -> state.authenticated = true
         -> state.authenticated_login_id = login_id
         -> return SUCCESS

注記
----
  - `ALREADY_AUTHENTICATED` は最初に判定される。何らかの session がすでに
    有効なら、`auth_login()` は `UNKNOWN_USER` や `LOCKED_OUT` まで進まない。
  - `change_password()` は認証済み session を要求するため、この core 単体では
    locked-out user は通常パスワード変更で回復できない。
  - `change_password() / SYSTEM_ERROR` 分岐は、
    `authenticated_login_id` が存在しないユーザーを指している破損 session state
    の場合にのみ発生する。
