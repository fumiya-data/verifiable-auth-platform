# ドキュメント索引

このディレクトリには、プロジェクトがどのように仕様化され、実装され、
検証されているかを示す主要文書の日本語版を置いています。

## プロジェクト状況

このプロジェクトは現在開発中です。各文書は、完成済み製品の利用者向け説明ではなく、
仕様、実装、TUI、テスト、観測可能性を揃えるための作業中の証拠資料として読んでください。
