# Audit Field Definitions

| Field | Type | Description |
| --- | --- | --- |
| `timestamp` | string | UTC event timestamp generated by the engine |
| `event_type` | string | Stable audit category |
| `login_id` | string | Login ID associated with the event |
| `result` | string | Stable machine-readable auth result code |

## Secret Handling

- Plaintext passwords must never appear in audit records.
- Password hashes and salts must never appear in audit records.
- `error.message` values in the CLI envelope must remain non-secret and
  diagnostic only.
